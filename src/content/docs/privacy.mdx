GTAV Mods Manager 以離線操作為主，沒有帳號系統、自有伺服器或遙測。核心模組管理資料保存在本機。

## 本機操作與網路查詢

安裝、解除安裝、衝突偵測與備份使用本機檔案及資料庫，不會因此發出網路請求。

更新檢查只有在你從設定或命令列手動要求時才會查詢 GitHub Releases。它讀取最新版本與連結，不會下載或安裝更新，也不會傳送遊戲路徑或模組清單。

模組來源的 Release 查詢也由你在模組詳細資訊中手動觸發。符合條件的 GitHub 來源會送出儲存庫擁有者與名稱以取得公開 Release 資訊；查詢不會傳送模組名稱、備註、安裝路徑、本機檔案或憑證。

## 選用 AI 功能

AI 功能預設關閉。只有在你啟用並使用 AI 功能後，相關文字才會傳送給你選擇的供應商。雲端請求可能依供應商條款收費；請先檢查要傳送的內容，因為翻譯輸入不會去識別化，可能包含路徑或其他敏感文字。

使用 AI 翻譯 INI／XML 時會傳送所選檔案的文字；要求 DLL 的 AI 翻譯草稿時會傳送擷取出的候選字串，不會傳送 DLL 二進位檔。API 金鑰存放在作業系統的憑證庫，不存於應用程式的 SQLite 資料庫或純文字設定。

要求 AI 診斷時，桌面版會傳送你貼入診斷欄位的文字；命令列工具也可讀取你指定的檔案或標準輸入。傳送前會以 `<home>` 取代目前使用者的家目錄路徑，但其他可識別或敏感文字仍可能保留。

## 錯誤回報草稿

命令列工具可列印預先填入應用程式版本、作業系統與錯誤文字的 GitHub Issue 草稿網址。建立或列印網址不會發出網路請求；開啟網址時，預填的標題與回報文字會傳送至 GitHub。只有在你檢視並提交後，Issue 才會發布。取代家目錄路徑並不能移除所有敏感資訊。
