Before using the desktop app’s mod installation feature, check the mod source and compatibility, and keep a backup of important game data.

## Before installing

- Confirm that the mod supports your GTA V version.
- Read the mod author’s installation instructions and dependency requirements.
- Avoid running installers or scripts from sources you cannot verify.
- If the desktop app shows a target path or file summary, review it before continuing.

## Use the desktop app

Open GTAV Mods Manager and use the installation flow available in your version. Confirm the mod and destination as prompted. If the data, path, or compatibility is unclear, stop and consult the mod author’s instructions.

This website cannot download or install real mods. The interactive demo only adds sample entries to the current page’s in-memory state.
