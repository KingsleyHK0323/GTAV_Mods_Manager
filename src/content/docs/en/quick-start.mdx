This guide outlines the desktop app at a high level. Interface labels may change between versions; follow the information shown by your installed desktop app.

## Before you begin

- Check that your GTA V version is compatible with the mod you plan to use.
- Use mod files from sources you trust and back up important game data first.
- Have the location of your GTA V game folder available.

## Basic workflow

1. Open the GTAV Mods Manager desktop app.
2. Follow the current app flow to choose or confirm the game folder.
3. Use the mod installation, language change, or installed-mod management feature.
4. Review the information shown before making a change, then check the item status in the library.

The [interactive demo](/en/demo/) uses sample data. It cannot install mods or connect to your game folder.
