Some mods provide files in multiple languages. The desktop app’s language change feature can handle supported mod language variants.

## Check before changing language

- Review the language list and version details from the mod author.
- Confirm that the language files match the mod version you use.
- Keep a recoverable backup and review the target item shown by the desktop app.

## Manage language variants

Use the language change flow available in your desktop app version, then select the mod and target language as prompted. Check the library state afterward and verify the result in game.

The language rows in the web demo are sample data. They do not read, download, or convert real files.
