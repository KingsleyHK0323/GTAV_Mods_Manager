## Does the web demo access my GTA V folder?

No. The demo uses fixed sample data and changes the list only in the current page’s memory. Its controls do not scan local files, call an API, or save demo actions.

## Can the demo install or convert real mods?

No. Real mod installation, mod translation, and installed-mod management are provided by the desktop app.

## Why does the demo reset when I refresh?

The demo does not persist sample actions. Refreshing or leaving the page loads the original sample data again.

## Where can I find the desktop app?

Visit the [GitHub project page](https://github.com/SpaceSquare640/GTAV_Mods_Manager), and verify the release source and version before downloading or running any file.
