這份指南概述桌面版的基本流程。實際介面標籤可能隨版本調整；操作時請以目前桌面版顯示的內容為準。

## 開始之前

- 確認你使用的 GTA V 版本與模組版本相容。
- 只使用你信任來源的模組檔案，並先備份重要遊戲資料。
- 準備好 GTA V 遊戲資料夾的位置。

## 基本流程

1. 開啟 GTAV Mods Manager 桌面應用程式。
2. 依桌面版目前提供的流程選擇或確認遊戲資料夾。
3. 使用模組安裝、語言轉換或已安裝模組管理功能。
4. 執行變更前先閱讀桌面版顯示的資訊；完成後回到清單檢查狀態。

本網站的 [互動 Demo](/GTAV_Mods_Manager/demo/) 使用範例資料，不能安裝模組或連接你的遊戲資料夾。
