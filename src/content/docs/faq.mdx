## 網站 Demo 會存取我的 GTA V 資料夾嗎？

不會。Demo 使用固定範例資料，只在目前頁面記憶體中更新清單；操作介面不會掃描本機檔案、呼叫 API 或儲存操作結果。

## Demo 可以安裝或轉換真實模組嗎？

不可以。真實模組安裝、模組翻譯與已安裝模組管理由桌面版提供。

## 為什麼重新整理後 Demo 回到原始資料？

Demo 不會持久化範例操作。重新整理或離開頁面會載入預設範例。

## 哪裡可以找到桌面版？

請查看 [GitHub 專案頁面](https://github.com/SpaceSquare640/GTAV_Mods_Manager)，並在下載或執行任何檔案前確認發布來源與版本資訊。
