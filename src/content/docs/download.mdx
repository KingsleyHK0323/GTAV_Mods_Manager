請只從 [GitHub Releases](https://github.com/SpaceSquare640/GTAV_Mods_Manager/releases) 下載桌面版安裝檔。可用版本與檔案以 Releases 頁面列出的內容為準。

## 安裝檔與校驗檔

- **Windows：** 安裝檔為 `.msi` 或 `.exe`，校驗檔是 `SHA256SUMS-windows.txt`。
- **Linux：** 安裝檔為 `.deb` 或 `.rpm`，校驗檔是 `SHA256SUMS-linux.txt`。

每個平台各有一份 SHA-256 校驗檔，列出該平台安裝檔的校驗值。請下載安裝檔及相同平台的校驗檔。

## 核對檔案

在 PowerShell 中計算 Windows 安裝檔的 SHA-256：

```powershell
Get-FileHash -LiteralPath 'path-to-installer.msi' -Algorithm SHA256
```

將輸出的 `Hash` 值與 `SHA256SUMS-windows.txt` 中相同檔名的校驗值比對。請把範例路徑替換成你下載的安裝檔路徑。

在 Linux 中，將安裝檔與校驗檔放在同一個資料夾後執行：

```bash
sha256sum -c SHA256SUMS-linux.txt
```

## Windows 安裝提示

安裝檔目前未簽章。Windows SmartScreen 可能在首次執行時顯示警告。下載前請確認來源為 GitHub Releases，並先核對該平台的 SHA-256 校驗值。
