### Profile switching safeguards (source validation pending)

<!-- OpenAI-Codex; OpenAI-Codex_Responsible: Source_Code -->
Before a profile switch enables or disables mods, its preflight checks recorded targets in the same database. It refuses identified overlaps within a mod to be enabled or disabled, between an outgoing mod and another active mod, and between an incoming mod and an active or different incoming mod, including same-target handoffs regardless of backup history. When an enable or disable is planned and any active mod in the same database has no recorded files, the switch is refused because that mod's targets cannot be established. This can block a switch unrelated to that mod, including a switch in another game directory. If no enable or disable is planned, this particular check is skipped; other checks can still refuse the switch. Path comparisons are conservative and may reject legitimate paths, but do not identify every filesystem alias. Enable can still overwrite an untracked file without a separate confirmation.
